### 1교시
| 주제 | 외울 것 |
|---|---|
| Ridge / Lasso | L2: λΣw² → 작게(0 아님), 닫힌 해 (XᵀX+λI)⁻¹Xᵀy / L1: λΣ\|w\| → 일부 정확히 0(특성 선택). 둘 다 **스케일링 먼저** |
| 편향-분산 | 기대 오차 = 편향² + 분산 + 잡음. 복잡↑ → 편향↓ 분산↑ |
| RF / 부스팅 | RF = 부트스트랩 + 노드별 특성 무작위(√p), 병렬, **분산↓**, OOB ≈ 36.8% / 부스팅 = 순차, 잔차(음의 기울기) 학습, **편향↓** |
| XGBoost | Ω = γT + ½λΣw² · w\* = −G/(H+λ) · Gain = ½[G_L²/(H_L+λ) + G_R²/(H_R+λ) − (G_L+G_R)²/(H_L+H_R+λ)] − γ · 결측 기본 방향 학습 · eta 0.3, max_depth 6 |
| 지표 | MAE(중앙값, 이상치 둔감) · RMSE(평균, 큰 오차 벌, **항상 ≥ MAE**) · P = TP/(TP+FP) · R = TP/(TP+FN) · F1 = 2PR/(P+R) = 2TP/(2TP+FP+FN) |
| 정상성 | 평균·분산 일정 + 공분산이 시차에만 의존. 추세 → 차분, 계절 → 계절 차분(y_t − y_(t−s)), 분산 증가 → 로그 |
| ARIMA | AR(p) = 과거 값 · MA(q) = 과거 오차 · I(d) = 차분 횟수. **AR → PACF가 p에서 끊김, MA → ACF가 q에서 끊김**. ADF H₀ = 비정상(단위근), KPSS H₀ = 정상 |
| CNN | O = ⌊(W − K + 2P)/S⌋ + 1 · 파라미터 = (K·K·C_in + 1)·C_out · 풀링 파라미터 0 |
| RNN | h_t = tanh(W_x x_t + W_h h_(t−1) + b) · 기울기 소실 → LSTM(망각·입력·출력 게이트, 셀 상태 덧셈)·GRU, 폭발 → 클리핑 |
| 활성화 | sigmoid′ 최대 0.25 · tanh 0 중심 · ReLU 죽은 뉴런 · 출력층: 회귀 선형 / 이진 sigmoid+BCE / 다중 softmax+CE |
| PyTorch | CrossEntropyLoss = log-softmax 내장(logit 입력) · BCEWithLogitsLoss = sigmoid 내장 · zero_grad → forward → backward → step · 평가 = eval() + no_grad() |
| Dropout | p = 끄는 확률, 학습 때 1/(1−p) 스케일, 평가 땐 안 끔 |
| Adam | m = β₁m + (1−β₁)g · v = β₂v + (1−β₂)g² · m̂ = m/(1−β₁ᵗ) · v̂ = v/(1−β₂ᵗ) · w −= η m̂/(√v̂+ε) · 기본 1e-3, 0.9, 0.999, 1e-8 · AdamW = 감쇠 분리 |

## 1. 1교시 객관식

**1-1.** 다음 중 일부 회귀 계수를 **정확히 0**으로 만들어 특성 선택 효과를 내는 것은?
① Linear(OLS) ② Ridge ③ Lasso ④ 정규방정식
> **정답 ③** — L1 벌점의 마름모 제약은 모서리(계수 = 0)에서 등고선과 만나기 쉽다. Ridge는 0에 가깝게만 줄인다. (1교시 노트 2-3)

① 편향↓ 분산↑ ② 편향↑ 분산↓ ③ 둘 다↓ ④ 변화 없음
> **정답 ②** — 가중치가 더 눌려 모델이 단순해진다(과소적합 쪽). (2-2, 1-3)

**1-3.** Lasso·Ridge를 쓰기 전에 거의 반드시 해야 하는 전처리는?
① 원-핫 인코딩 ② 특성 표준화 ③ 로그 변환 ④ 이상치 제거
> **정답 ②** — 벌점이 계수 크기에 걸리므로 단위가 다른 특성이 섞이면 불공평하다. (2-2)

**1-4.** Random Forest의 트리들을 서로 다르게 만드는 방법이 **아닌** 것은?
① 부트스트랩 표본 ② 노드마다 특성 일부만 후보로 ③ 이전 트리의 잔차를 학습 ④ 트리마다 다른 난수

**1-5.** 부트스트랩 표본에서 특정 샘플이 한 번도 뽑히지 않을 확률(n이 클 때)은 약?
① 5% ② 18% ③ 37% ④ 63%
> **정답 ③** — (1 − 1/n)ⁿ → 1/e ≈ 0.368. 이 샘플들로 OOB 오차를 잰다. (3-2)

**1-6.** XGBoost에서 어떤 분할의 Gain(γ를 뺀 값)이 음수다. 어떻게 되나?
① 무조건 분할 ② 분할하지 않음 ③ 학습률을 낮춤 ④ 잎 가중치를 0으로
> **정답 ②** — Gain 식 끝의 −γ가 "분할에 필요한 최소 이득" 역할(가지치기). (3-3)

**1-7.** XGBoost 잎 j의 최적 출력값은? (G, H = 1차·2차 미분의 합)
① G/H ② −G/(H+λ) ③ −H/(G+λ) ④ G²/(H+λ)
> **정답 ②** — G²/(H+λ)는 목적함수 감소량 쪽 식이다. (3-3)

**1-8.** 배깅과 부스팅에 대한 설명으로 옳은 것은?
① 배깅은 순차, 부스팅은 병렬 ② 배깅은 주로 편향, 부스팅은 주로 분산을 줄인다 ③ 배깅은 주로 분산, 부스팅은 주로 편향을 줄인다 ④ 둘 다 트리 수를 늘리면 과적합이 반드시 줄어든다
> **정답 ③** (3-4)

**1-9.** 예측 오차가 [2, 2, 2, 2]일 때와 [0, 0, 0, 8]일 때를 비교한 것으로 옳은 것은?
① MAE가 다르다 ② 두 경우 MAE는 같고 RMSE는 뒤쪽이 크다 ③ RMSE가 같다 ④ 뒤쪽 RMSE가 MAE보다 작다

**1-12.** 약정상성의 조건이 **아닌** 것은?
① 평균이 일정 ② 분산이 일정 ③ 공분산이 시차에만 의존 ④ 값이 정규분포를 따른다

## 2. 1교시 주관식 (코드·Pseudo Code·서술)

**1-S1.** 선형 회귀의 MSE 손실을 w로 미분한 식을 쓰고, 경사하강법 의사코드를 작성하라.
> **답** — ∂MSE/∂w = (2/n)·Xᵀ(Xw − y). Ridge면 기울기에 + 2λw. 의사코드는 아래. (1교시 12-3)

```text
w ← 0
repeat epochs:
    err ← X·w − y
    w ← w − η·(2/n)·Xᵀ·err
```

**1-S2.** 정밀도·재현율·F1을 계산하는 함수를 numpy로 작성하라(분모 0 처리 포함).
> **답** — 1교시 노트 12-2 코드. 핵심 키워드: `(p == 1) & (y == 1)`, `if tp + fp else 0.0`, 조화평균.

**1-S3.** 수치적으로 안정한 softmax를 작성하고 왜 최댓값을 빼는지 설명하라.
> **답** — `z = z − z.max(axis=1, keepdims=True); e = np.exp(z); return e / e.sum(axis=1, keepdims=True)`. exp가 넘치지(inf) 않게 하려는 것이고, 분자·분모에 같은 상수가 곱해져 결과는 같다. (12-10)

**1-S4.** 빈칸을 채워라: `opt.____(); loss = loss_fn(model(x), y); loss.____(); opt.____()` / 평가 때 필요한 두 가지는?
> **답** — `zero_grad`, `backward`, `step`. 평가 때는 `model.eval()`과 `with torch.no_grad():`. (12-15)

**1-S5.** 결정트리가 최적 분할을 찾는 과정을 의사코드로 쓰라(지니 불순도 사용).
> **답** — 1교시 노트 12-6. 키워드: 모든 특성 × 모든 임계값, 자식 불순도의 **샘플 비율 가중 평균**이 최소인 분할.

**1-S6.** 월별 판매 시계열에 ARIMA를 적용하는 절차를 순서대로 서술하라.
> **답** — ① 그림으로 추세·계절성·분산 확인 → ② 로그 변환·차분(d)·계절 차분(D, s = 12)으로 정상화, ADF/KPSS로 확인 → ③ ACF·PACF로 p, q(계절 P, Q) 후보 → ④ 적합 후 AIC·BIC 비교 → ⑤ 잔차가 백색잡음인지(Ljung-Box) → ⑥ 예측 후 차분 되돌리기. (6-7)

**1-S7.** 학습 손실은 계속 줄고 검증 손실은 10 epoch부터 오른다. 상태와 처방 3가지를 쓰라.
> **답** — 과적합. 처방: 조기 종료(검증 최저점 가중치), Dropout·weight decay(L2), 데이터 증강·데이터 추가, 모델 축소 중 3개. (1-2, 10장)

**1-S8.** Adam 한 스텝을 의사코드로 쓰라.
> **답** — 1교시 노트 11-2 식 또는 12-11 `adam_step`. t는 1부터.

**1-S9.** 입력 3×32×32 이미지에 Conv(3→16, 3×3, 패딩 1) → MaxPool 2×2 → Conv(16→32, 3×3, 패딩 0)을 적용했다. 최종 출력 크기와 두 합성곱 층의 파라미터 수는?
> **답** — Conv1: 32 유지 → Pool: 16 → Conv2: 16 − 3 + 1 = 14 → **32×14×14**. 파라미터: (3·3·3+1)·16 = **448**, (3·3·16+1)·32 = **4,640**. 풀링은 0.

**1-S10.** 정형·이미지·시계열 데이터 각각에 알맞은 모델과 이유를 한 줄씩 쓰라.
> **답** — 정형: 트리 앙상블(특성마다 뜻이 다르고 스케일링 불필요, 강한 기준선) / 이미지: CNN(지역 연결·가중치 공유로 공간 패턴, 위치가 바뀌어도 같은 특징) / 시계열: LSTM·GRU 또는 ARIMA(순서와 과거 의존성을 은닉 상태·자기회귀로 반영). (8-1)

**1-S11.** 은닉층 하나(ReLU)와 softmax 출력을 가진 신경망의 역전파를 numpy로 구현하라.
> **답** — 1교시 노트 12-12. 키워드: dz = (p − 원-핫)/n, dW2 = h1ᵀdz, db2 = Σdz, dh1 = dz W2ᵀ, da1 = dh1 × (a1 > 0), dW1 = Xᵀda1. 기울기 모양 = 파라미터 모양.

**1-S12.** 제곱 오차 그래디언트 부스팅의 학습 과정을 의사코드로 쓰고, 왜 "그래디언트"인지 설명하라.
> **답** — F₀ = 평균 → 반복: r = y − F, r에 작은 트리 h를 맞춤, F ← F + η·h. ½(y − F)²를 F로 미분한 값의 음수가 잔차 r이라서 "음의 기울기를 맞춘다" = 그래디언트 부스팅. (1교시 12-8)
