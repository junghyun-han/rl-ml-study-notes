## 1. "주어진 PPO로 Gym 이산 환경(CartPole 등) 성능을 높여라"

## 2. "PPO로 MuJoCo(연속 행동) 성능을 높여라"
**가장 빠른 길 (실행 확인)**: `mock_ppo_plus.py` 하나로 개선 전·후를 같은 스텝·같은 시드로 돌려 비교한다.
```bash
python mock_ppo_plus.py --env InvertedPendulum-v5 --steps 100000 --seed 0                       # 개선 전
python mock_ppo_plus.py --env InvertedPendulum-v5 --steps 100000 --seed 0 --norm-obs --norm-reward --lr-decay --target-kl 0.02 --save-best   # 개선 후
```
| 실험 | 1000 도달 | 도달 뒤 | KL / clip 비율 (후반) | 최종 평가 (탐험 없이 10판) |
|---|---|---|---|---|
| 개선 전 | 5만 1천 스텝 | 7만~8만 스텝에 922로 흔들림 | 0.004~0.007 / 0.04~0.08 | 1000.0 ± 0.0 |
| 개선 후 (옵션 전부) | **4만 1천 스텝** | **끝까지 1000 유지** | **0.001~0.003 / 0.005~0.025** | 1000.0 ± 0.0 |

**답안 문장**: "최종 평가는 둘 다 만점(1000)이라 최종 점수로는 차이가 없다. 대신 관측·보상 정규화, 학습률 선형 감소, KL 조기 종료를 켜자 만점 도달이 5만 1천 → 4만 1천 스텝으로 빨라졌고, 도달 뒤 흔들림(922까지 하락)이 사라졌다. 후반 KL·clip 비율이 작아진 것이 근거다. 시드 1개라 시드를 늘려 확인이 필요하다."
- 쉬운 환경(InvertedPendulum)은 기본 설정으로도 만점이라, 개선 효과는 **도달 속도·안정성**으로 보여 준다. 어려운 환경(Hopper 등)은 학습 스텝이 훨씬 많이 필요하다.

**직접 06 코드를 고치는 경우** (주어진 코드가 06과 비슷할 때)
**순서**
1. 연속 행동용 PPO를 쓴다: 정책이 평균을 내고 `log_std`를 따로 학습, `log_prob(…).sum(-1)`로 차원 합산, 환경에 넣을 때만 범위로 자름. 코드 `06_ppo_continuous.py`에서 `gym.make("Pendulum-v1")` **두 곳**(16줄 학습용, 91줄 평가용)을 원하는 환경으로 바꾼다.
   - 확인: `InvertedPendulum-v5`로 바꾸고 총 스텝을 8,192로 줄여 한 번 실행 → 오류 없이 평가 점수 58.7 → 82.0 → 112.7 → 136.0으로 상승(동작 확인용 짧은 실행이라 최종 성능 아님, 만점 1000).
   - `06`은 끝에서 `results/ppo_continuous.txt`를 덮어쓴다. 원래 결과를 남기려면 그 줄의 파일 이름을 바꾼다.
2. `06`에는 **보상 정규화가 이미 들어 있다**(17줄 `NormalizeReward`). 여기에 **관측 정규화를 더한다**(연속 제어 공개 구현의 기본 관행): 16~17줄을 T1 한 줄로 바꾼다.
3. 평가는 **관측 정규화 값을 복사·고정한 별도 환경, 보상 정규화는 끈 원래 점수**로: 91줄의 평가 환경을 T2로 바꾼다.
4. 출렁이면 학습률을 학습 중 선형으로 줄임 → T3.
5. 시드 3개로 최종 평가 → T6.

**코드: 환경 만드는 줄을 이렇게 바꾼다**
```python
from action_toolbox import make_env, make_eval_env, evaluate_env
env = make_env("InvertedPendulum-v5", norm_obs=True, norm_reward=True, clip_action=True, gamma=GAMMA)   # 06의 16~17줄 대신
# ... 학습 ...
ev = make_eval_env("InvertedPendulum-v5", env, clip_action=True)                           # 06의 91줄 평가 환경 대신
print(evaluate_env(ev, lambda o: model.mu(torch.as_tensor(o, dtype=torch.float32)).detach().numpy()))  # 평균 행동으로(06은 model.mu)
```
**코드: 학습률 선형 감소 (업데이트 루프 끝에 한 줄)**
```python
from action_toolbox import linear_decay
sched = linear_decay(opt, total_updates=args.steps // N_STEPS)   # opt 만든 바로 뒤
# for update in ...:
#     ... (업데이트) ...
sched.step()                                                      # 업데이트 한 번 끝날 때마다
```
**주의**: 관측 정규화를 켜고 학습했으면 평가 때도 같은 정규화가 필요하다(안 하면 정책이 다른 크기의 입력을 받아 점수가 망가짐). 보상 정규화는 학습용이라 점수 보고에는 쓰지 않는다.

## 3. "SAC로 Pendulum·MuJoCo 성능을 높여라"
**순서**
1. `mock_sac.py`에 환경 이름만 바꿔 돌린다.
2. 점수가 낮아도 **α가 아직 크게 줄어드는 중이면 수렴 전** → 설정을 바꾸지 말고 스텝부터 늘린다.
3. 스텝을 늘려도 정체면: 학습률(3e-4 → 1e-4), 처음 무작위 스텝(1000 → 5000), 배치(256 → 512) 순으로 하나씩.

**코드**

```bash
python mock_sac.py --env InvertedPendulum-v5 --steps 30000 --seed 0   # 1000.0 ± 0.0
```
**답안 문장**: "9천 스텝 65점은 설정 문제가 아니라 학습량 부족이었다. α가 줄며 탐험에서 활용으로 넘어간 시점(1만 8천~2만 1천 스텝)과 성능 급상승 시점이 맞는다."

## 4. "점수가 무작위 기준선과 똑같다" (안 배움)
**순서와 코드**
1. 업데이트가 실제로 일어나는지: 업데이트 전후 가중치 비교
```python
w0 = actor[0].weight.clone();  # ... 업데이트 한 번 ...
print((actor[0].weight - w0).abs().sum())     # 0이면 opt.step()이 안 불렸거나 옵티마이저에 파라미터가 없음
```
2. 행동을 정책에서 뽑는지(계속 `env.action_space.sample()`이 아닌지), 시작 무작위 스텝이 전체보다 길지 않은지.
3. 보상 부호와 종료 처리: terminated만 미래 0, truncated는 부트스트랩.
4. 연속 행동: `log_prob(…).sum(-1)`, 버퍼에는 자르기 전 행동.
5. 오류 메시지가 나오면 → 에러 메시지 대처표.

## 5. "올라가다가 무너진다" (급락)
**순서**
1. 로그에서 KL·clip 비율이 급증했는지 확인 → 2. 학습률↓ → 3. **KL 조기 종료** → 4. epoch↓·clip ε↓ → 5. 그래도 무너지면 **가장 좋았을 때 모델을 저장해 그것으로 평가**(답안에 "최고 시점 모델로 평가"라고 밝힘).

**한 파일로 (실행 확인)**: 아래 끼워 넣기를 이미 다 넣은 `mock_ppo_plus.py`에 옵션만 켠다.
```bash
python mock_ppo_plus.py --env <환경> --steps <스텝> --lr 1e-4 --epochs 4 --target-kl 0.02 --save-best
```
- 로그 줄 끝에 `KL 조기 종료`가 찍히면 그 업데이트에서 정책 변화가 커서 멈춘 것이다. `--save-best`면 "최고 시점 모델로 평가 (학습 리턴 …)"이 찍힌다.

**코드: KL 조기 종료 (PPO 업데이트 부분)**
```python
from action_toolbox import approx_kl
TARGET_KL = 0.02
for _ in range(EPOCHS):
    stop = False
    for idx in torch.randperm(N_STEPS).split(MB):
        dist = Categorical(logits=actor(O[idx]))
        new_logp = dist.log_prob(A[idx])
        if approx_kl(new_logp, LP[idx]) > 1.5 * TARGET_KL:   # 너무 많이 바뀌면 이번 업데이트는 여기서 멈춤
            stop = True; break
        ratio = (new_logp - LP[idx]).exp()
        # ... (기존 손실·업데이트 그대로) ...
    if stop:
        break
```
**코드: 최고 모델 저장**
```python
from action_toolbox import save_model, load_model
best = -1e9
# 업데이트 루프 안, 로그 찍는 곳에서:
if np.mean(returns[-20:]) > best:
    best = np.mean(returns[-20:]); save_model(actor, "best_actor.pt")
# 학습 끝나고 평가 전에:
load_model(actor, "best_actor.pt")
```

## 부록: 도구 전체 코드 (`action_toolbox.py`, 실행 확인)
```python
"""상황별 행동 코드집에서 쓰는 도구 (모두 실행 확인: python action_toolbox_check.py)
정규화 켜기 · 평가용 환경(정규화 값 복사·고정) · 학습률 바꾸기/줄이기 · PPO 근사 KL · 모델 저장/불러오기 · 시드 여러 개 실행 · 학습 곡선
"""
import copy
import re
import subprocess
import sys
import numpy as np
import torch
import gymnasium as gym


# ── T1 환경 만들기: 관측·보상 정규화, 행동 자르기 켜고 끄기 ──
def make_env(env_id, norm_obs=False, norm_reward=False, clip_action=False, gamma=0.99):
    env = gym.make(env_id)
    if clip_action:
        env = gym.wrappers.ClipAction(env)                      # 연속 행동을 범위 안으로 자름
    if norm_obs:
        env = gym.wrappers.NormalizeObservation(env)            # 관측을 이동 평균·분산으로 정규화
    if norm_reward:
        env = gym.wrappers.NormalizeReward(env, gamma=gamma)    # 보상 크기 맞추기(학습용)
    return env


def find_wrapper(env, cls):
    """감싼 층들을 안쪽으로 따라가며 cls 종류의 Wrapper를 찾음"""
    e = env
    while True:
        if isinstance(e, cls):
            return e
        if not hasattr(e, "env"):
            return None
        e = e.env


# ── T2 평가용 환경: 관측 정규화 값을 복사해 고정, 보상 정규화는 끔(원래 점수로 평가) ──
def make_eval_env(env_id, train_env, clip_action=False):
    src = find_wrapper(train_env, gym.wrappers.NormalizeObservation)
    ev = make_env(env_id, norm_obs=src is not None, clip_action=clip_action)
    if src is not None:
        dst = find_wrapper(ev, gym.wrappers.NormalizeObservation)
        dst.obs_rms = copy.deepcopy(src.obs_rms)                # 학습 때 쌓은 평균·분산 복사
        dst.update_running_mean = False                         # 평가 중에는 갱신하지 않음
    return ev


def evaluate_env(env, policy_fn, episodes=10, seed=1000):
    """이미 만든 환경 객체로 평가 (정규화된 관측을 정책에 넣고, 점수는 원래 보상으로)"""
    scores = []
    for i in range(episodes):
        obs, _ = env.reset(seed=seed + i)
        done, total = False, 0.0
        while not done:
            obs, r, term, trunc, _ = env.step(policy_fn(obs))
            total += r
            done = term or trunc
        scores.append(total)
    return float(np.mean(scores)), float(np.std(scores))


# ── T3 학습률 바꾸기 / 학습하며 선형으로 줄이기 ──
def set_lr(opt, lr):
    for g in opt.param_groups:
        g["lr"] = lr


def linear_decay(opt, total_updates):
    """매 업데이트 끝에 sched.step() 호출 → 학습률이 처음 값에서 0까지 선형으로 감소"""
    return torch.optim.lr_scheduler.LinearLR(opt, start_factor=1.0, end_factor=0.0, total_iters=total_updates)


# ── T4 PPO 근사 KL: 미니배치마다 계산해 목표를 넘으면 그 업데이트의 남은 epoch를 멈춤 ──
def approx_kl(new_logp, old_logp):
    log_ratio = new_logp - old_logp
    return ((log_ratio.exp() - 1) - log_ratio).mean().item()


# ── T5 가장 좋은 모델 저장·불러오기 ──
def save_model(model, path):
    torch.save(model.state_dict(), path)


def load_model(model, path):
    model.load_state_dict(torch.load(path))
    return model


# ── T6 시드 여러 개 실행해 FINAL 줄에서 평가 점수 모으기 ──
def run_seeds(script, args, seeds):
    scores = []
    for s in seeds:
        out = subprocess.run([sys.executable, script, *args, "--seed", str(s)], capture_output=True, text=True).stdout
        m = re.search(r"FINAL seed \d+: 평가 10판 (-?[\d.]+)", out)
        scores.append(float(m.group(1)))
        print(f"seed {s}: {scores[-1]}")
    r = np.array(scores)
    print(f"평균 {r.mean():.1f} ± {r.std():.1f} (시드 {len(r)}개)")
    return scores


# ── T7 학습 곡선 그리기 (시드별 판 리턴 → 이동평균) ──
def plot_curves(curves, path, w=20, title=""):
    import matplotlib
    matplotlib.use("Agg")
    import matplotlib.pyplot as plt
    for name, ret in curves.items():
        ret = np.asarray(ret, dtype=float)
        k = min(w, len(ret))
        plt.plot(np.convolve(ret, np.ones(k) / k, mode="valid"), label=name)
    plt.xlabel("episode"); plt.ylabel(f"return (moving avg {w})"); plt.title(title); plt.legend()
    plt.savefig(path, dpi=120); plt.close()
```
