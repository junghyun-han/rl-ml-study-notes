# 3교시 순서대로 따라 하기 + 예상 문제 전수 목록 (Physical AI 실습)

> **실제 기출이 아니다.** 강화학습 실습 범위 문장마다 나올 만한 실습 문제를 뽑았다. 실습 문항에 논문이 참고자료로 붙는 경우를 대비해 논문 식을 구현하는 유형(G장)도 넣었다.
> 문제마다: **보여야 할 것**(채점자가 볼 핵심) → **쓸 코드**(이미 실행 확인한 코드의 위치) → **함정**.
> 코드 위치 표기: `00`~`12` = `code/` 파일(3교시 실습노트에 전부 실림), `E·R` = 쉬운 설명본의 서술형 코드, `X1`~`X7` = 이 문서 맨 뒤 코드(이번에 새로 쓰고 실행 확인).
> 판단 기준(무엇부터, 언제 무엇을)은 **3교시 상황별 대처표**에 있다.

## 0. 시험 시작부터 제출까지 순서대로 (그대로 따라 하기)
> 아래 순서를 오늘 밤 한 번 그대로 따라 해 보고 손에 익힌다. 단계마다 칠 코드는 이 문서 맨 뒤 **W1~W5**(실행 확인)와 기존 코드에 있다. 시간은 120분 기준 예시.

### 0-1. 문제 읽기 (0~5분)
1. 문제 설명을 끝까지 읽고, 메모에 네 가지를 적는다.
   - ① 환경 이름(예: `CartPole-v1`, `Pendulum-v1`, 직접 만든 환경)
   - ② 개선하라는 **지표**(평균 리턴? 성공률? 도착 스텝?)
   - ③ **제한**(시간·스텝 수, 바꾸면 안 되는 코드나 설정)
   - ④ **제출물**(코드? 숫자? 해석 글? 셋 다?)
2. **참고자료(논문)** 탭이 있으면 어떤 식을 구현하라는 건지 표시한다(G장).
3. 문제 유형을 정한다 → 아래 바로가기.

| 문제가 이렇게 생겼으면 | 바로 갈 곳 |
|---|---|
| 빈칸 채우기·알고리즘 구현 | B장 |
| 성능을 올려라 | 0-2부터 끝까지 순서대로 + C장 |
| 보상 함수를 설계하라 | 0-2, 0-3 → D장 순서 → 0-7, 0-8 |
| 로그·곡선을 해석하라 | E장 |
| 경로를 찾아라 | F장 |
| 논문 식을 구현하라 | G장 |

### 0-2. 환경 확인 (5~10분)
1. **W1** `inspect_env("환경이름")`을 실행한다.
2. 출력에서 세 가지를 메모한다.
   - 행동이 **이산**(`Discrete`)인지 **연속**(`Box`)인지
   - 판 최대 길이
   - 1,000스텝 걸리는 시간
3. 학습에 쓸 수 있는 스텝 수를 어림한다. 학습은 신경망 업데이트 때문에 환경만 돌릴 때보다 훨씬 느리다. 그래서 **0-5에서 짧게 한 번 돌려 실제 속도를 잰다.**
   - 참고(내 맥 CPU): 무작위 행동 1,000스텝은 CartPole 0.01초, Pendulum 0.02초. DQN 학습은 CartPole 5만 스텝에 약 25초.

### 0-3. 기준선 재기 (10~15분)
1. **W3** `random_baseline("환경이름")` → 학습 전 바닥 점수(평균 ± 표준편차)를 기록한다.
   - 확인 값: CartPole 23.5 ± 13.2, Pendulum −1326.8 ± 254.9.
2. **제공 코드가 있으면** 바꾸지 말고 그대로 한 번 짧게 돌려 점수를 기록한다. 이게 "개선 전" 점수다.
3. **W5** `log_result`로 첫 줄을 남긴다. 표 형식: | 실험 이름 | 바꾼 것 | 점수 | 메모 |

### 0-4. 알고리즘 정하기 (15분)
| 행동 | 상태 | 1순위 | 직접 작성해야 하면 따라 쓸 구조 |
|---|---|---|---|
| 이산 | 작은 격자(상태 번호) | 표 Q-learning | `01`, R1 |
| 이산 | 연속값 벡터 | PPO (또는 DQN) | `05`, R5·R6 / DQN은 `02`, 설명본 16-1 뼈대 |
| 연속 | 연속값 벡터 | SAC (또는 PPO 연속) | `07`, R7 / `06` |
| 전이 확률이 주어짐 | — | 가치 반복 | `10`, R8 |

### 0-5. 첫 학습: 돌아가는지부터 (15~35분)
1. 처음엔 **스텝을 작게**(예: 1만) 잡고 끝까지 도는지만 확인한다.
2. 확인할 것:
   - 오류 없이 끝나는가
   - 리턴이 무작위 기준선보다 **올라가는 방향**인가
   - 1만 스텝에 몇 초 걸렸나 → 남은 시간으로 최종 학습 스텝 수를 정한다
3. 기준선보다 낮거나 전혀 안 움직이면 → **버그부터**: done 처리, 보상 부호, 행동 범위, 연속 log_prob 합산, zero_grad 순서, 타깃·이점 no_grad/detach, SAC의 rsample.
4. 처음 돌릴 설정값은 대처표 3장(PPO 2048·10·64·3×10⁻⁴·0.2 / SAC 3×10⁻⁴·256·0.005·α 자동 / DQN 1×10⁻³·128·500).
5. **W5**로 기록.

### 0-6. 개선: 한 번에 하나씩 (35~90분)
1. 아래 순서대로 **한 가지만** 바꾸고, 같은 스텝 수로 돌려 비교한다.
   1. 보상 크기·정규화(`NormalizeReward`)
   2. 관측 정규화(`NormalizeObservation`)
   3. 학습률(출렁이거나 급락하면 ↓, 너무 느리면 ↑)
   4. 탐험(PPO 엔트로피 계수, SAC α, DQN ε 감소 속도)
   5. 학습 스텝 늘리기
   6. 문제가 허용하면 보상 설계(잠재 기반 성형, D장)
2. 바꿀 때마다 **W5**로 한 줄 기록: 무엇을 왜 바꿨고, 점수가 어떻게 됐나.
3. 나빠졌으면 바로 되돌리고 다음 항목으로.
4. 곡선이 이상하면 대처표 5장 증상표로 원인을 찾는다.

### 0-7. 최종 실행과 평가 (90~110분)
1. 가장 좋았던 설정으로, 시간이 되면 **시드 3개**로 최종 학습한다.
2. **W2** `evaluate(정책함수, "환경이름")`로 **탐험 없이** 평가한다.
   - 이산: argmax 행동
   - 연속: 평균 행동(SAC는 tanh(μ) × 범위)
3. 시드별 점수를 **W4** `summarize([...])`로 "평균 ± 표준편차 (시드 n개)"로 만든다.

### 0-8. 답안 쓰고 제출 (110~120분)
1. 대처표 9장 틀을 그대로 쓴다.
   - ① 기준선
   - ② 바꾼 것들과 결과(W5 표)
   - ③ 최종 점수
   - ④ 왜 좋아졌는지 해석(곡선·KL·엔트로피 근거)
   - ⑤ 한계
2. 답안을 제출하고 제출이 완료됐는지 확인한다.
3. 종료 5분 전에 빠진 문항이 없는지 확인한다.

### 0-9. 실험 기록 예시 (W5로 남긴 표)
| 실험 | 바꾼 것 | 점수 (평가 10판) | 메모 |
|---|---|---|---|
| 기준선 | 무작위 행동 | 23.5 ± 13.2 | 학습 전 바닥 |
| 실험 1 | DQN 기본(lr 1×10⁻³, 타깃 500, 5만 스텝) | 시드별 191.7 / 500 / 135.8 | 시드 편차 큼 |
| 실험 2 | 타깃망 끔(비교용) | 9.8 / 9.8 / 9.8 | 붕괴 → 타깃망 필요 |
| 실험 3 | PPO(논문 설정, 10만 스텝) | 약 5만 스텝부터 학습 중 리턴 500 유지 | 안정적 → 최종 선택 |

(위 숫자는 모두 내 실험 결과. 시험에서는 그 환경의 실제 숫자로 채운다.)

## A. 환경 다루기 (gymnasium)

**A1. 주어진 환경을 무작위 정책으로 돌려 기준 점수를 구하라.**
- 보여야 할 것: `reset` 반환 2개, `step` 반환 5개, terminated/truncated로 판 종료, 여러 판 평균.
- 쓸 코드: `00` 1번 부분.
- 함정: 옛 gym(반환 4개)과 헷갈리기, 한 판만 보고 판단.

**A2. 문제에 설명된 규칙대로 환경 클래스를 작성하라(상태·행동·보상·종료).**
- 보여야 할 것: `observation_space`·`action_space` 정의, `reset`(시드·초기 상태), `step`(상태 변화 → 종료 판정 → 보상 → 5개 반환), `check_env` 통과.
- 쓸 코드: `00` 2번 부분 `GridEnv`.
- 함정: 관측 dtype을 공간 정의와 다르게(float32 vs int), 시간 제한을 terminated로 처리.

**A3. Wrapper로 보상을 바꾸거나 관측·보상을 정규화하라.**
- 보여야 할 것: 상태가 필요한 보상은 `gym.Wrapper`의 `step`을 고침, 원래 보상은 `info`에 남김, 정규화는 `NormalizeObservation`·`NormalizeReward`.
- 쓸 코드: `00` 3번 부분 `DistanceShaping`, `06`의 `NormalizeReward`.
- 함정: `RewardWrapper`는 상태를 못 봄, `reset`에서 이전 Φ 초기화 누락.

**A4. 시간 제한 처리 버그를 찾아 고쳐라.**
- 보여야 할 것: 버퍼·타깃에서 `done`에 **terminated만** 넣기, truncated는 부트스트랩(PPO는 보상에 γV(다음 상태)를 더함).
- 쓸 코드: `02` 4-5절, `05` 7-3절.
- 함정: CartPole 500스텝 잘림을 실패로 처리 → 오래 버틴 상태 가치 과소평가.

## B. 알고리즘 구현 (빈칸 채우기·전체 작성)

**B1. ε-greedy와 Q-learning(또는 SARSA) 갱신을 작성하고, 절벽 과제에서 두 방법의 경로 차이를 설명하라.**
- 보여야 할 것: 목표 한 줄의 차이(max vs 실제 다음 행동), `(not terminated)`, 학습 후 greedy 경로.
- 쓸 코드: `01`, R1. 결과: SARSA 안전한 길(−21.8) / Q-learning 최단 길(−50.5), 시드 10개 모두 같음.
- 함정: SARSA에서 다음 행동을 두 번 뽑기, α가 크면 잘 안 가 본 칸의 Q가 덜 배워짐.

**B2. 전이 확률이 주어진 MDP를 가치 반복(또는 정책 반복)으로 풀고 정책의 성공률을 재라.**
- 보여야 할 것: 벨만 식 한 줄 `Σ p(r + γV′(1−done))`, 수렴 판정 Δ < θ, greedy 정책 추출, 시뮬레이션 성공률.
- 쓸 코드: `10`, R8. 결과: FrozenLake 4×4에서 두 방법 같은 답, 성공률 74.1%.
- 함정: 끝나는 전이에서 미래 가치 0을 빼먹음, 할인된 V와 성공률을 같은 것으로 착각.

**B3. 밴딧에서 greedy·ε-greedy·UCB를 구현해 비교하라.**
- 보여야 할 것: 증분 평균, 동점 무작위, UCB의 "안 당긴 팔 먼저", 여러 문제 평균.
- 쓸 코드: `11`, R9. 결과: 최적 팔 비율 30% / 78% / 85%.

**B4. DQN의 빈칸(리플레이 버퍼, 목표값, 손실, 타깃망 갱신)을 채워 CartPole을 학습하라.**
- 보여야 할 것: 무작위 배치, `gather`로 Q(s,a), 목표는 `no_grad`, `(1 − done)`, 주기적 타깃 복사.
- 쓸 코드: `02`, R3, 설명본 16-1 뼈대.
- 함정: `a.unsqueeze(1)` 누락, 타깃망을 옵티마이저에 넣음, 탐험 난수 시드 미고정.

**B5. DQN을 Double DQN 또는 Dueling DQN으로 바꿔라.**
- 보여야 할 것: Double = 지금 망 argmax로 고르고 타깃망으로 평가 / Dueling = Q = V + (A − A의 평균).
- 쓸 코드: R3(`double=True`), **X1**.
- 함정: Dueling에서 평균을 빼지 않으면 V와 A가 구분되지 않음.

**B6. n-step 목표값으로 바꿔라.**
- 보여야 할 것: n개 보상을 γ로 할인해 더하고, 끝나지 않았으면 γⁿ × (n스텝 뒤 가치)를 더함.
- 쓸 코드: **X2**.
- 함정: 중간에 판이 끝나면 그 뒤를 더하지 않기.

**B7. REINFORCE를 구현하라(기준선 포함).**
- 보여야 할 것: 뒤에서부터 할인 리턴, 정규화(기준선 효과), 손실 = −Σ log π × G.
- 쓸 코드: `03`, R2.
- 함정: 리턴을 앞에서부터 계산, 부호(최대화 → 음수로 최소화).

**B8. Actor-Critic 손실을 작성하라.**
- 보여야 할 것: TD 목표 r + γV(s′)(1−done), δ를 `detach`한 Actor 손실, Critic MSE.
- 쓸 코드: `04`, R4.

**B9. PPO의 GAE·clip 손실·업데이트 루프를 작성하라.**
- 보여야 할 것: 뒤에서부터 GAE, `(1 − done)`으로 끊기, ratio = exp(new − old), 이점 정규화, min/clamp, 가치 손실·엔트로피, 미니배치 × epoch, 기울기 클리핑.
- 쓸 코드: `05`, R5·R6.
- 함정: 옛 log_prob를 기울기 있는 채로 저장, 엔트로피 부호.

**B10. 이산 PPO를 연속 행동 환경용으로 고쳐라.**
- 보여야 할 것: Normal 분포 + 학습되는 log σ, log_prob·엔트로피를 차원 합산, 환경엔 clip한 행동·버퍼엔 원래 행동.
- 쓸 코드: `06`.

**B11. SAC의 정책(tanh 가우시안), Q 목표, 정책 손실, α 조절, Polyak 갱신을 작성하라.**
- 보여야 할 것: `rsample`, log π 보정(− Σ log(1 − tanh²)), 다음 행동은 지금 정책에서 새로 뽑기, min(Q1′, Q2′) − α log π, τ = 0.005.
- 쓸 코드: `07`, R7.
- 함정: `sample()` 사용, 보정 누락, 타깃 계산에 기울기 흐름.

**B12. TD3의 세 가지 장치를 설명하거나 DDPG 코드에 넣어라.**
- 보여야 할 것: ① Q 두 개 중 작은 값 ② 정책을 Q보다 덜 자주 업데이트 ③ 타깃 행동에 작은 잡음을 더하고 범위로 자름.
- 쓸 코드: 없음(설명형). SAC의 min Q·타깃망 코드(R7)와 구조가 같다.

**B13. 시연 데이터로 행동 복제(모방학습) 정책을 학습하라.**

### X1. Dueling DQN 머리

▸ `extra_snippets.py` 7–18줄
```python
# ── X1 Dueling DQN 머리: Q = V + (A − A의 평균) ──
class DuelingQ(nn.Module):
    def __init__(self, obs_dim, n_act, h=128):
        super().__init__()
        self.body = nn.Sequential(nn.Linear(obs_dim, h), nn.ReLU())
        self.v = nn.Linear(h, 1)           # 상태 가치 V(s)
        self.a = nn.Linear(h, n_act)       # 행동별 이점 A(s, a)

    def forward(self, x):
        z = self.body(x)
        a = self.a(z)
        return self.v(z) + a - a.mean(dim=1, keepdim=True)
```
- 몸통에서 나온 특징으로 V(상태 가치) 하나와 A(행동별 이점) 여러 개를 따로 낸다.
- `a − a.mean(...)`: 행동별 이점의 평균을 빼야 V와 A가 하나로 정해진다(빼지 않으면 V에 아무 값을 더하고 A에서 빼도 같은 Q가 나와 구분이 안 됨).

### X2. n-step 목표값

▸ `extra_snippets.py` 21–27줄
```python
# ── X2 n-step 목표값 ──
def n_step_target(rewards, gamma, bootstrap_value, done):
    """rewards = [r_t, …, r_(t+n−1)], bootstrap_value = n스텝 뒤 상태의 가치 추정(max Q 또는 V)"""
    G = sum(gamma ** k * r for k, r in enumerate(rewards))
    if not done:
        G += gamma ** len(rewards) * bootstrap_value
    return G
```
- n개 보상을 γ로 할인해 더하고, 판이 끝나지 않았으면 n스텝 뒤 가치를 γⁿ 곱해 더한다. 확인: [1, 1, 1], γ = 0.5, 뒤 가치 8 → 2.75.

### X3. 행동 복제

▸ `extra_snippets.py` 30–40줄

```python
# ── X3 행동 복제(behavior cloning): 시연 (상태, 행동)으로 지도학습 ──
def behavior_cloning(states, actions, n_act, epochs=200, lr=1e-2):
    policy = nn.Sequential(nn.Linear(states.shape[1], 64), nn.ReLU(), nn.Linear(64, n_act))
    opt = torch.optim.Adam(policy.parameters(), lr=lr)
    loss_fn = nn.CrossEntropyLoss()          # 연속 행동이면 nn.MSELoss()
    for _ in range(epochs):
        opt.zero_grad()
        loss = loss_fn(policy(states), actions)
        loss.backward()
        opt.step()
    return policy
```
- 시연 (상태, 행동) 쌍을 정답이 있는 분류 문제로 학습한다. 연속 행동이면 손실을 MSE로 바꾼다.

```python
# ── X4 GRPO 그룹 상대 이점: 같은 과제를 여러 번 시도한 보상들을 그룹 안에서 정규화 ──
```

### X5. 하위 목표 숙련도와 가중치

▸ `extra_snippets.py` 49–53줄

```python
# ── X5 하위 목표 숙련도·보상 가중치 (Agentic-VLA 보상 합성 식) ──
def update_subgoal_weights(c, success, alpha=0.9):
    """c_k ← α·c_k + (1 − α)·성공(0/1),  가중치 w_k = 1 − c_k"""
    c = alpha * c + (1 - alpha) * success
    return c, 1 - c
```
- 숙련도 c는 최근 성공 여부의 지수 이동평균. 가중치 w = 1 − c → 아직 못하는 하위 목표의 보상을 크게.

### X6. 경로 다듬기

```python
# ── X6 경로 다듬기(shortcut): 두 점을 직선으로 이어도 충돌이 없으면 중간 점을 지움 ──
def shortcut(path, edge_free, iters=300, seed=0):
    rng = np.random.default_rng(seed)
    path = [np.asarray(p, dtype=float) for p in path]
    for _ in range(iters):
        if len(path) < 3:
            break
        i, j = sorted(rng.choice(len(path), 2, replace=False))
        if j - i >= 2 and edge_free(path[i], path[j]):
            path = path[:i + 1] + path[j:]
    return path
```
- 경로 위 두 점을 무작위로 골라, 직선으로 이어도 충돌이 없으면 사이의 점들을 지운다. 반복할수록 짧아진다.

### W1. 환경 확인

▸ `exam_workflow.py` 9–24줄
```python
# ── W1 환경 확인: 이산/연속, 판 길이, 1,000스텝 걸리는 시간 ──
def inspect_env(env_id):
    env = gym.make(env_id)
    env.reset(seed=0)
    env.action_space.seed(0)
    kind = "이산" if isinstance(env.action_space, gym.spaces.Discrete) else "연속"
    print("관측 공간:", env.observation_space)
    print("행동 공간:", env.action_space, "→", kind)
    print("판 최대 길이:", env.spec.max_episode_steps)
    t0 = time.time()
    for _ in range(1000):
        _, _, term, trunc, _ = env.step(env.action_space.sample())
        if term or trunc:
            env.reset()
    print(f"1,000스텝(무작위 행동) {time.time() - t0:.2f}초")
    return kind
```
- `isinstance(env.action_space, gym.spaces.Discrete)`: 행동 공간이 정수 몇 개 중 하나인지(이산) 확인. 아니면 Box(연속).
- `env.spec.max_episode_steps`: 시간 제한(truncated가 나는 스텝 수).
- 무작위로 1,000스텝 돌린 시간으로 환경 속도를 잰다.

### W2. 정책 평가

▸ `exam_workflow.py` 27–41줄
```python
# ── W2 정책 평가: 탐험 없는 정책으로 여러 판, 평균·표준편차·평균 길이 ──
def evaluate(policy_fn, env_id, episodes=10, seed=1000):
    env = gym.make(env_id)
    scores, lengths = [], []
    for i in range(episodes):
        obs, _ = env.reset(seed=seed + i)
        done, total, n = False, 0.0, 0
        while not done:
            obs, r, term, trunc, _ = env.step(policy_fn(obs))
            total += r
            n += 1
            done = term or trunc
        scores.append(total)
        lengths.append(n)
    return float(np.mean(scores)), float(np.std(scores)), float(np.mean(lengths))
```
- `policy_fn(obs)`는 관측을 받아 행동을 돌려주는 함수. 학습한 모델이면 예: `lambda o: int(q(torch.as_tensor(o)).argmax())`.
- 학습 환경과 다른 시드(1000부터)로 평가해 같은 판만 외운 게 아닌지 본다.

### W3. 무작위 기준선

▸ `exam_workflow.py` 44–48줄
```python
# ── W3 무작위 기준선: 학습 전 "바닥 점수" ──
def random_baseline(env_id, episodes=10):
    space = gym.make(env_id).action_space
    space.seed(0)
    return evaluate(lambda obs: space.sample(), env_id, episodes)
```
- `space.seed(0)`: 무작위 행동도 시드를 줘야 다시 돌려도 같은 결과(재현성).

```python
# ── W4 시드 여러 개 결과 요약 ──
def summarize(results):
    r = np.asarray(results, dtype=float)
    return f"{r.mean():.1f} ± {r.std():.1f} (시드 {len(r)}개)"
```

```python
# ── W5 실험 기록: 한 줄씩 표로 남기기 ──
def log_result(table, name, change, score_text, note=""):

    print(f"| {name} | {change} | {score_text} | {note} |")
```
