## 5. 3교시 실습 예상 과제
> 각 과제의 정답 코드는 `code/` 파일과 3교시 실습노트 해당 장. 시험장에서는 16장 뼈대부터 쓰고 살을 붙인다.

**P1. 보상 함수 설계 실험** 〔핵심〕
"주어진 격자(또는 gym) 환경에서 희소 보상으로 학습한 결과를 기준선으로, 보상 함수를 설계해 성능을 개선하고 비교하라."
> **풀이 순서** — ① 원래 지표(성공률·도착 스텝) 정하기 ② `gym.Wrapper`의 `step`에서 r + γΦ(s′) − Φ(s) (끝 상태 Φ = 0), `info`에 원래 보상 저장 ③ 같은 알고리즘·같은 시드 여러 개로 학습 ④ **원래 지표로** 비교표 ⑤ 해킹 여부 확인. 코드: `00_gym_basics.py` 3번, `08_reward_shaping_grid.py`. 실습노트 2-3, 10장.

**P2. DQN 완성하기**
"리플레이 버퍼, ε-greedy, 타깃 계산, 타깃망 업데이트 빈칸을 채우고 CartPole을 학습하라. Double DQN으로 바꿔라."
> **체크포인트** — `gather(1, a.unsqueeze(1))`, 타깃은 `no_grad`, `(1 − terminated)`, `load_state_dict` 주기 복사, Double = 온라인 argmax + 타깃 gather. 코드: `02_dqn_cartpole.py`, 뼈대 16-1.

**P3. PPO 핵심 구현**
"GAE와 clip 손실 함수를 구현하고, ε 또는 학습률을 바꿔 결과를 비교·해석하라."
> **체크포인트** — 뒤에서부터 GAE, `(1 − done)`으로 끊기, ret = adv + val, ratio = exp(new − old), 이점 정규화, min/clamp, 엔트로피는 빼기, 로그(KL·clip 비율·엔트로피)로 해석. 코드: `05_ppo_discrete.py`(`--lr`, `--clip` 인자로 비교 가능), 뼈대 16-2.

**P4. SAC 정책과 손실**
"tanh 가우시안 정책의 log_prob를 구현하고, Q 타깃·정책 손실·Polyak 업데이트를 작성하라."
> **체크포인트** — `rsample`, `log_prob(u).sum(-1) − log(scale·(1 − tanh²) + 1e-6).sum(-1)`, 타깃에 min(Q′) − α log π(a′), 정책 손실 α log π − min Q, θ′ ← (1−τ)θ′ + τθ. 코드: `07_sac_pendulum.py`, 뼈대 16-3·16-4.

**P5. RRT 구현**
"장애물이 있는 2D 지도에서 RRT로 경로를 찾고 길이를 계산하라. RRT\*로 바꿔 비교하라."
> **체크포인트** — goal bias, 최근접, steer(같은 점이면 건너뛰기), **선분 충돌 검사**, 부모 역추적, 경로 길이 합. RRT\*는 반경 이웃에서 부모 고르기 + rewire. 코드: `09_rrt.py`, 뼈대 16-5.

**P6. 학습 로그 해석**
"주어진 학습 곡선·로그(리턴, 가치 손실, 엔트로피, KL)를 보고 문제를 진단하고 개선안을 제시해 실행하라."
> **답 틀** — 증상 → 원인 → 확인 지표 → 처방 → 다시 실행해 비교(시드 여러 개). 2교시 노트 7장 표, 3교시 실습노트 15장 그림(타깃망 끄면 붕괴, 1-step AC 출렁임, PPO 안정, SAC 샘플 효율).

**P7. 정책 경사·Actor-Critic 손실 작성**
"할인 리턴을 계산하고 REINFORCE 손실을 작성하라 / TD 이점으로 Actor·Critic 손실을 작성하라."
> **체크포인트** — 뒤에서부터 G = r + γG, 정규화(기준선), loss = −Σ log π · G / δ = r + γV(s′)(1−T) − V(s), Actor엔 δ.detach(). 코드: `03_reinforce_cartpole.py`, `04_actor_critic_cartpole.py`.

**P8. 가치 반복·정책 반복**
"FrozenLake의 전이 확률로 가치 반복과 정책 반복을 구현하고, 두 결과가 같은지와 정책의 실제 성공률을 확인하라."
> **체크포인트** — `env.unwrapped.P`, `q_from_v`, 제자리 갱신, delta < θ, greedy 정책, 정책 반복은 평가 ↔ 개선 후 정책이 같으면 종료, 시뮬레이션으로 성공률(약 0.74). 코드: `10_value_iteration.py`, 뼈대 16-6.

**P9. 밴딧 탐험 비교**
"10개 팔 밴딧에서 greedy·ε-greedy·UCB를 구현해 평균 보상과 최적 팔 비율을 비교하라."
> **체크포인트** — 동점은 무작위로, 증분 평균, UCB는 안 당긴 팔 먼저, 여러 문제(RUNS) 평균. 코드: `11_bandit.py`, 뼈대 16-7.

**P10. A\* 경로 탐색**
"격자 지도에서 A\*로 최단 경로를 찾고, h = 0(Dijkstra)과 펼친 노드 수를 비교하라."
> **체크포인트** — `heapq`에 (f, g, 노드), closed면 건너뛰기, g 갱신 조건, parent 역추적, 맨해튼(4방향에서 admissible). 코드: `12_astar.py`, 뼈대 16-8.
