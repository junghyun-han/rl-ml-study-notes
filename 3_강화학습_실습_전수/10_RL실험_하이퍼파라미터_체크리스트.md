# 하이퍼파라미터 시도 범위와 제출 전 체크리스트

> 성능을 올릴 때 **어떤 값을 시도할지** 후보. 각 값의 출처를 표시했다: **논문** = 원 논문에서 확인한 값, **내 실험** = 직접 돌려 확인한 값, **관행** = 공개 구현에서 흔히 쓰는 범위(정답이 아니라 시도 후보).
> 원칙: **한 번에 하나만** 바꾸고, 같은 스텝·같은 시드로 비교한다.

## 1. 공통
| 값 | 기본 | 시도 후보 | 바꾸는 신호 |
|---|---|---|---|
| 학습률 | 3×10⁻⁴ (PPO·SAC 논문) | 1×10⁻⁴, 3×10⁻⁴, 1×10⁻³ (관행) | 출렁임·급락 → ↓ / 너무 느림 → ↑ |
| γ (할인율) | 0.99 (PPO·SAC 논문) | 0.95~0.995 (관행) | 먼 미래가 중요하고 판이 길면 ↑, 짧고 즉각적인 과제면 ↓ (대략 1/(1−γ) 스텝 앞까지 봄) |
| 은닉층 | PPO 64×2 tanh, SAC 256×2 ReLU (논문) | 64·128·256 (관행) | 과제가 복잡한데 학습이 정체되면 키움 |
| 학습 스텝 | 시간 안에서 최대 | — | 리턴이 아직 오르는 중이면 늘림(내 실험 MuJoCo: 9천 스텝 65 → 3만 스텝 1000) |
| 시드 | 0, 1, 2 | 3~5개 | 결과 차이가 작으면 늘려서 확인 |

## 2. PPO
| 값 | 기본 | 시도 후보 | 메모 |
|---|---|---|---|
| clip ε | 0.2 (논문) | 0.1, 0.2, 0.3 | 논문 MuJoCo 비교: 0.1 → 0.76, **0.2 → 0.82**, 0.3 → 0.70 |
| GAE λ | 0.95 (논문) | 0.9~0.98 (관행) | ↓ 분산↓ 편향↑ / ↑ 반대 |
| 한 번에 모으는 스텝 | 2048 (논문 MuJoCo) | 512~2048 | Atari 설정은 128스텝 × 8개 환경(논문) |
| epoch | 10 (논문 MuJoCo) | 3~10 | KL·clip 비율이 크면 ↓(Atari 설정은 3, 논문) |
| 미니배치 | 64 (논문 MuJoCo) | 32~256 | |
| 엔트로피 계수 c₂ | 0 (논문 MuJoCo) / 0.01 (논문 Atari) | 0, 0.001, 0.01 | 엔트로피가 금방 0이면 ↑ |
| 가치 손실 계수 c₁ | 0.5 (관행), 1 (논문 Atari) | 0.5~1 | |
| 기울기 클리핑 | 0.5 (관행) | 0.5~1 | |
| 이점 정규화 | 켬 (관행) | — | |
| 관측·보상 정규화 | 연속 제어에서 켬 (관행) | — | `NormalizeObservation`, `NormalizeReward` |

## 3. SAC
| 값 | 기본 | 시도 후보 | 메모 |
|---|---|---|---|
| 학습률 | 3×10⁻⁴ (논문) | 1×10⁻⁴~1×10⁻³ | |
| 배치 | 256 (논문) | 128~512 | |
| τ (Polyak) | 0.005 (논문) | 0.005~0.01 | 논문 그림: τ가 크면(타깃이 빨리 움직이면) 불안정 |
| 버퍼 | 10⁶ (논문) | 10⁵~10⁶ | 짧은 과제는 10⁵이면 충분(내 실험) |
| 처음 무작위 스텝 | 1,000 (내 실험) | 1,000~10,000 (관행) | |
| α | 자동(목표 엔트로피 = −행동 차원 수, 후속판) | 고정 0.05~0.2 (관행) | 원 논문은 α 대신 보상 크기 조절(환경별 5~20) |
| 평가 | 평균 행동(논문) | — | 탐험 없이 |

## 4. DQN
| 값 | 기본 | 시도 후보 | 메모 |
|---|---|---|---|
| 학습률 | 1×10⁻³ (내 CartPole) | 1×10⁻⁴~1×10⁻³ | 내 비교(시드 1개): 2.5×10⁻⁴·5×10⁻⁴보다 1×10⁻³이 나았음 |

## 5. 제출 전 체크리스트
**코드**
- [ ] 처음부터 끝까지 오류 없이 돈다(스텝을 줄여 한 번 더 확인)
- [ ] 시드 고정: `random`, `numpy`, `torch`, `env.reset(seed=…)`, `env.action_space.seed(…)`
- [ ] 종료 처리: terminated만 미래 가치 0, truncated는 부트스트랩
- [ ] 타깃·이점은 `no_grad` / `detach`, 학습 순서 `zero_grad → backward → step`
- [ ] 연속 행동: log_prob 합산, 행동 범위(tanh·clip), 버퍼엔 원래 행동

**실험**
- [ ] 무작위 기준선과 개선 전 점수를 기록했다
- [ ] 한 번에 하나씩 바꿨고 실험 기록표가 있다
- [ ] 최종 평가는 탐험 없이(argmax / 평균 행동), 학습과 다른 시드로 10판
- [ ] 결과를 평균 ± 표준편차(시드 n개)로 적었다
- [ ] 설계 보상이 아니라 원래 지표로 평가했다(보상 설계 문제)

**답안**
- [ ] 보고 틀 7항목: 문제 정리 → 기준선 → 방법과 이유 → 실험 기록 → 최종 결과 → 해석 → 한계
- [ ] 해석에 근거(곡선, KL·clip 비율, 엔트로피, α, Q 크기)를 붙였다
- [ ] 제출이 완료됐는지 확인했다
